# Elad Weller - Portfolio

Welcome to my personal portfolio! This site showcases my projects, skills, and experience as a full-stack developer.

## 🚀 About This Site

This portfolio is built with Jekyll and hosted on GitHub Pages. It features:

- **Responsive Design:** Looks great on all devices
- **Project Showcase:** Detailed pages for each project with screenshots and demos
- **Skills Section:** Overview of technologies and tools I work with
- **Contact Information:** Easy ways to get in touch

## 📁 Site Structure

- `index.md` - Home page with introduction and featured projects
- `projects/` - Directory containing all project pages
- `projects/index.md` - Complete projects listing
- `_config.yml` - Jekyll site configuration

## 🛠️ Technologies Used

- **Static Site Generator:** Jekyll
- **Theme:** Minima (GitHub Pages compatible)
- **Hosting:** GitHub Pages
- **Version Control:** Git

## 🚀 Getting Started

To run this site locally:

```bash
# Clone the repository
git clone https://github.com/eladw917/eladw917.github.io.git

# Install Jekyll (if not already installed)
gem install jekyll bundler

# Install dependencies
bundle install

# Run the development server
bundle exec jekyll serve

# Open http://localhost:4000 in your browser
```

## 📝 Adding New Projects

To add a new project:

1. Create a new markdown file in the `projects/` directory
2. Use the following front matter:
   ```yaml
   ---
   layout: page
   title: Project Name
   permalink: /projects/project-name/
   ---
   ```
3. Add project details, screenshots, and links
4. Update the `projects/index.md` to include the new project
