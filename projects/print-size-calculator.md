# Print Size Calculator

A comprehensive web application that helps photographers, designers, and print professionals calculate optimal print sizes, resolutions, and aspect ratios for various printing scenarios.

## 🌟 Features

- **Multiple Calculation Modes**: Standard print sizes, custom dimensions, aspect ratio conversions
- **Resolution Calculator**: PPI/DPI recommendations for different print types
- **Print Cost Estimator**: Calculate printing costs based on size and material
- **Unit Conversions**: Seamlessly switch between inches, centimeters, pixels, and more
- **Preset Templates**: Quick access to common print formats (8x10, 11x14, A4, etc.)
- **Professional Guidelines**: Industry-standard recommendations for print quality

## 🛠️ Technologies Used

- **Frontend**: React, TypeScript, Tailwind CSS
- **Backend**: Node.js, Express.js
- **Deployment**: Vercel
- **Domain**: Custom domain (printsizecalculator.com)

## 📊 Impact

- **Users Served**: 10,000+ monthly active users
- **Industries**: Photography, graphic design, printing services
- **User Satisfaction**: 4.8/5 average rating
