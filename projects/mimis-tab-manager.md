# Mimi's Tab Manager

A powerful Chrome extension that helps users organize, manage, and optimize their browser tabs with intelligent grouping, session saving, and productivity features.

## 🚀 Features

- **Smart Tab Grouping:** Automatically group tabs by domain, topic, or custom categories
- **Session Management:** Save and restore tab sessions with one click
- **Tab Search:** Quickly find and switch between open tabs
- **Duplicate Detection:** Identify and remove duplicate tabs automatically
- **Memory Optimization:** Monitor and optimize tab memory usage
- **Keyboard Shortcuts:** Power user shortcuts for efficient tab management
- **Sync Across Devices:** Sync tab sessions across multiple devices

## 🛠️ Technologies Used

- **Frontend:** JavaScript, HTML5, CSS3
- **Chrome Extension APIs:** Tabs API, Storage API, Commands API
- **Build Tools:** Webpack, Babel
- **Deployment:** Chrome Web Store
