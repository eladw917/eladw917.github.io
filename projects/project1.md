# E-commerce Platform

A full-featured e-commerce platform built with modern web technologies, featuring user authentication, product management, shopping cart functionality, and secure payment processing.

## 🚀 Features

- **User Authentication:** Secure login/registration with JWT tokens
- **Product Management:** Admin dashboard for adding/editing products
- **Shopping Cart:** Persistent cart with local storage
- **Payment Processing:** Integration with Stripe for secure payments
- **Order Management:** Complete order tracking and history
- **Responsive Design:** Mobile-first design that works on all devices
- **Search & Filtering:** Advanced product search and category filtering

## 🛠️ Technologies Used

- **Frontend:** React, Redux for state management, React Router
- **Backend:** Node.js, Express.js, MongoDB with Mongoose
- **Authentication:** JWT tokens, bcrypt for password hashing
- **Payment:** Stripe API integration
- **Deployment:** Heroku for backend, Netlify for frontend
- **Styling:** CSS Modules with responsive design
