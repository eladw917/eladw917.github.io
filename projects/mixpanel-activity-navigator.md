# Mixpanel Activity Navigator

Navigate Mixpanel activity feeds efficiently - filter events, track properties, and analyze user timelines

## 🌟 Features

- **Feed Cleaner**: Hide unwanted events from activity feeds for cleaner analysis
- **Property Finder**: Quickly find and highlight important user properties
- **Quick Timeline**: Create custom timelines with selected events
- **Event Filtering**: Filter by event type for focused analysis
- **Property Tracking**: See property values at a glance without scrolling

## 🛠️ Technologies Used

- **Frontend**: JavaScript, Chrome Extension APIs
- **Integration**: Mixpanel API
- **Deployment**: Chrome Web Store

## 📊 Impact

- **Users**: Product managers, data analysts, and customer success teams
- **Efficiency**: Faster and more efficient user activity analysis
- **Privacy**: No data leaves your browser, works only on Mixpanel.com
